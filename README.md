# VOLTA — школа танцев в Митино

Next.js App Router + TypeScript. Адаптивный сайт в editorial-стиле, реальные материалы из `public`, страницы направлений, форма заявки и техническая SEO-база.

## Запуск

Node.js >=20.9 (проверяется на Node 24).

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Открыть http://localhost:3000. Production: `npm run build` и `npm start`.

Если Node не в PATH в этом окружении: `export PATH=/home/kozetta/.nvm/versions/node/v24.13.0/bin:$PATH`.

## Перед запуском для посетителей

Контакты в `components/Footer.tsx` и реквизиты в `app/privacy/page.tsx`, `app/consent/page.tsx` — явно демонстрационные. Нельзя включать приём реальных данных до их замены. Уточнить возраст, цены, расписание, маршрут и юридические условия.

В `.env.local` задать реальный `SITE_URL` без завершающего `/`, HTTPS `LEAD_WEBHOOK_URL`, при необходимости `LEAD_WEBHOOK_TOKEN`. Принимающая система должна надёжно сохранять заявку до ответа 2xx. Данные: name, phone, direction, consent, consentVersion, createdAt, source. Не логировать персональные данные. Выбрать инфраструктуру хранения и сроки удаления согласно утверждённой политике школы. На прокси/хостинге настроить лимит размера запроса и rate limiting для `/api/leads`; honeypot не заменяет защиту от массовых запросов.

После проверки данных и доставки поставить `SITE_READY=true`, выполнить новую сборку. Эта настройка включает индексацию и доставку. До неё форма возвращает честный 503, сайт имеет noindex, robots запрещает обход, sitemap пустой. Нет ложного сообщения об успешной заявке и локального накопления контактов.

`YANDEX_VERIFICATION` — код подтверждения Вебмастера. Аналитика не подключена. Карта использует сторонний iframe Яндекса.

## Проверки

```sh
npm test
npm run build
npm run typecheck
```

Сервер: `POST /api/leads`; 400 — некорректные поля/согласие, 403 — другой Origin, 413 — тело >4 KiB после чтения, 503 — доставка не подключена, 502 — ошибка доставки, 200 — принимающий сервер ответил 2xx. Тестировать успешную доставку на своём тестовом webhook до production. Защита размера до чтения тела — задача reverse proxy.

SEO-разведка, источники и план запуска: [docs/seo-research.md](docs/seo-research.md).
