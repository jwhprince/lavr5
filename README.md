# VOLTA — школа танцев в Митино

Next.js App Router + TypeScript. Статический сайт: локальные фотографии WebP и видео, страницы направлений, демонстрационная форма записи.

## Локальный запуск

Node.js >=20.9 (проверено на Node 24).

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000. Для статической сборки: `npm run build`; результат в `out/`. `npm start` запускает локальный просмотр готовой сборки (Node.js, порт 3000). Для сборки с подпапкой запускать с тем же `NEXT_PUBLIC_BASE_PATH=/lavr5 npm start`. Порт можно поменять через `PORT=3002`.

## GitHub Pages

1. Загрузить репозиторий на GitHub в ветку `main` (либо изменить ветку в `.github/workflows/pages.yml`).
2. В Settings → Pages → Source выбрать **GitHub Actions**.
3. Workflow соберёт и опубликует папку `out/`. Его также можно запустить вручную через Actions.

Путь репозитория и адрес сайта берутся из `configure-pages`. Для ручной сборки под подпапку:

```sh
NEXT_PUBLIC_BASE_PATH=/lavr5 SITE_URL=https://USERNAME.github.io/lavr5 npm run build
```

Для корневого домена `NEXT_PUBLIC_BASE_PATH` оставить пустым. Пути задаются при сборке. Никаких секретов в публичных переменных. Содержимое `.env*`, `node_modules/`, `.next/` и `out/` исключено из git.

## Демонстрационная версия

Форма не принимает имя и телефон, не отправляет запросы и не сохраняет данные. Направление можно выбрать, кнопка объясняет будущий процесс записи. Контакты и юридические реквизиты остаются явными заглушками. Индексация отключена по умолчанию; workflow всегда задаёт `SITE_READY=false`.

Серверный обработчик сохранён в `server/leads-route.ts` для будущего полноценного запуска. На GitHub Pages серверных обработчиков нет. Для подключения записи потребуется серверный хостинг, возврат обработчика в `app/api/leads/route.ts`, снятие `output: 'export'`, восстановление рабочей формы, настройка доставки и проверка реальных контактов и документов. Одного изменения переменной окружения недостаточно.

Карта Яндекса загружается лениво. Видео не скачивается до воспроизведения (`preload="none"`); внешних шрифтов и библиотек анимации нет. При `prefers-reduced-motion` анимации отключаются.

## Проверки

```sh
npm test
npm run build
npm run typecheck
```

Тесты валидатора относятся к сохранённому серверному обработчику. Результаты проверки интерфейса: `docs/validation.md`.

## Анимации и предупреждения браузера

Появления блоков и текста запускаются один раз при входе в экран через `IntersectionObserver`. Контент виден без JavaScript. У бегущей строки есть кнопка паузы, движение останавливается вне экрана. Мобильное меню закрывается по Escape, возвращает фокус и блокирует взаимодействие с фоном. При изменении системной настройки уменьшения движения уже скрытые блоки сразу открываются.

На `<html>` задан `data-scroll-behavior="smooth"`, чтобы Next.js корректно обрабатывал переходы между страницами.

Если React сообщает о лишних `data-lt-installed` или `suppresshydrationwarning` на `<html>`, проверьте страницу в профиле без расширений: проект этих атрибутов не добавляет. В чистом Chromium гидратация и клиентские переходы проверены без предупреждений. Глобальное подавление предупреждений не включено, чтобы реальные ошибки оставались видны.
