# Проверки

- `npm test`: тесты валидации заявки прошли (валидные данные, согласие, телефон, направление, honeypot, неверные типы).
- `npm run typecheck`: без ошибок.
- `npm run build`: production-сборка и предварительная генерация страниц прошли; повторная сборка включает исправление Origin. После неё уточнены HTML-ограничения длины телефона; TypeScript проверен повторно.
- HTTP: главная, три направления, документы, robots и sitemap — 200; неизвестная страница — 404.
- POST /api/leads: корректная демо-заявка — 503 без ложного успеха; неверные поля — 400; сторонний Origin — 403. Исправлено сравнение localhost с внутренним адресом Next.js.
- Chromium: просмотр первого экрана на desktop 1440 px и mobile 390 px. Скриншоты в `docs/previews`. Desktop снимок сделан до небольшого улучшения вертикального кадрирования hero.
- Доставка в реальную CRM/webhook не проверялась: получатель не настроен. Карта зависит от доступности Яндекса. Полный автоматизированный прогон браузерных взаимодействий и Lighthouse не выполнялся.
